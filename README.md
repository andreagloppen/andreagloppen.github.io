# København-gave til Ingrid

Åbn `index.html` i en browser.

## Som giver
1. Klik **Redigér min tilgængelighed**.
2. Klik på en lørdag eller søndag. Hele weekenden markeres som ledig.
3. Kalenderen går til og med juni 2027.
4. Klik **Lav gavelink** og kopiér hele URL'en.
5. Host `index.html` på en statisk webhost og send gavelinket til Ingrid.

## Som modtager
- Grønne weekender er de weekender, giveren har markeret som ledige.
- Ingrid kan klikke på én grøn weekend.
- Hun kan kopiere et link med sit valg og sende det tilbage.
